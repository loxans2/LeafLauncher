# Code de conduite

Leaf Launcher suit le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En bref : sois respectueux et bienveillant, avec tout le monde, quels que soient son âge, son
niveau, son origine ou son identité. Harcèlement, insultes, attaques personnelles et contenus
déplacés ne sont pas tolérés, dans les issues, les pull requests comme dans les discussions.

Un problème ? Signale-le aux mainteneurs par **Security › Report a vulnerability** sur le dépôt
(c'est privé), ou en message privé sur le serveur `play.leafsmp.fr`. Chaque signalement sera lu
et traité avec discrétion.
